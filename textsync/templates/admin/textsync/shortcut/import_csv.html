📋 CSV Format

Your CSV file should have these columns:

  • key - The shortcut trigger (required)
  • content_type - Either text or html
  • value - Plain text content
  • html_value - Rich text/HTML content
  • sets - Set names separated by |

Example:

key,content_type,value,html_value,sets
/hello,text,Hello World!,,General
/sig,html,,<p><b>John Doe</b><br>CEO</p>,Personal|Signatures
/ty,text,Thank you for your email.,,Support
