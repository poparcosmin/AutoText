AutoText

Sistem de text expansion pentru Chrome. Tipărești o cheie scurtă, apeși Tab, primești textul complet — în Gmail, Docs sau orice câmp text editabil.

⚡ Expand instant

Tastezi buna + Tab → "Bună ziua,". Funcționează pe orice site, în orice câmp editabil.

🔄 Sincronizare cu server

Biblioteca ta de shortcuts e stocată pe serverul tău (privat). Cache local pentru folosire offline.

📂 Birou + Personal

Set partajat cu echipa pentru standardizare + set personal pentru fiecare utilizator.

🎲 Variabile dinamice

[[date]], [[greeting]], [[var:nume]], plus aliases și variante random A/B pentru anti-template feel.
